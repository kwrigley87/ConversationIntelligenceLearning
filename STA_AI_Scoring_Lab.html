01 · Mission

AI Scoring is only as good as the question

AI Scoring uses the evaluation question, answer choices and help text to construct the prompt used to score the interaction.

Your challenge

You inherit a traditional 10-question customer service evaluation form. Before you switch on AI Scoring, decide which questions are suitable as written, which need rework, and which cannot be reliably answered from the interaction alone.

Golden rule: Ask AI to score evidence the interaction can support — not an assumption about what happened outside the conversation.

03 · Curveballs

Three questions designed to catch you out

Use these after the review: they expose three common problems with traditional quality questions.

Curveball 01 · The invisible action

“Did the agent check the billing system before answering?”
Not Observable. The conversation may show the answer the agent gave, but it does not prove which system the agent accessed. Score only evidence available in the interaction.

Curveball 02 · The vague judgement

“Did the agent provide good customer service?”
Needs Rework. “Good customer service” is an overall judgement. Define the observable behaviour or outcome you actually want to score.

Curveball 03 · The process claim

“Did the agent follow all company procedures?”
Needs Rework. It combines multiple requirements and may depend on evidence outside the interaction. Narrow it to one clearly observable criterion.
Golden Nugget: Useful does not automatically mean scoreable. The question must be answerable from evidence available to the evaluator — and the scoring guidance needs to remove ambiguity.
04 · Build in Genesys Cloud

Build it for real

Now take what you have learned and build a small AI Scoring evaluation in Genesys Cloud.

HANDS-ON TASK

Build → test → inspect → improve

Use the revised questions and help text from the review as your starting point. The goal is not a perfect form — it is to test how AI Scoring behaves on a real interaction.

1

Create the form

Create an Agent Auto-Evaluation form and add a small set of AI Scoring questions.

2

Use the revised questions

Choose questions you judged AI Ready or have successfully rewritten. Keep the wording specific and observable.

3

Add answer choices + help text

Make answers clearly distinguishable. Help text should explain what evidence supports each answer and what should not be inferred.

4

Publish and evaluate

Publish the form, open a suitable historical interaction and manually create the evaluation.

5

Use Virtual Supervisor

Select Virtual Supervisor as the evaluator so the evaluation is completed automatically.

6

Inspect the result

Review the selected answer, Reason for Selection and confidence. Compare the result with what you believe a human evaluator should select.

7

Change one thing and test again

Improve either the question or its help text, then re-run the test and see whether the result becomes more useful.

05 · Takeaway

Before you scale AI Scoring...

Use these checks whenever you review or design an AI Scoring question.

1 · Observable?Can the interaction contain the evidence?
2 · Specific?Is there one clear behaviour or outcome?
3 · Answers clear?Can each answer be distinguished from the others?
4 · Help text useful?Does it define what evidence counts for each answer?
5 · Validated?Have you compared AI output with human judgement?

The point isn't “AI can score this.”

The point is: “AI can score this from clear, observable evidence — and we have tested whether the result is trustworthy.”

Remember

AI Scoring uses the question, answer choices and help text to determine how the interaction should be evaluated. Better inputs make the scoring task clearer. Human review remains part of validation and exception handling.
